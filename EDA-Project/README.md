# Exploratory Data Analysis (EDA) Project

## Objective
Analyze customer dataset to discover patterns, trends, and correlations.

## Features
- Statistical summaries
- Correlation analysis
- Histograms
- Scatter plots
- Heatmaps
- Structured insights report

## Run Project

```bash
pip install -r requirements.txt
python main.py
```

## Outputs
- Correlation Heatmap
- Age Distribution
- Income vs Spending
- Region Distribution
- EDA Insights Report
